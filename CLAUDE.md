# MMES — Project Rules

## Language

- Primary language for all UI text (labels, headings, buttons, links, aria-labels, validation/error messages, tooltips): **English**.
- Secondary language, used only for input `placeholder` example text: **Mexican Spanish (es-MX)**.
- This rule applies only to this app (MMES). Do not use Vietnamese in UI copy going forward, even though the surrounding conversation/comments may be in Vietnamese.

Example:
```html
<label for="employee-id">Employee ID</label>
<input id="employee-id" placeholder="Ej. HS-00231">
```
